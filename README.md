# Guitar Fretboard Interval Trainer

ギター指板上でルート音からの度数（インターバル）の絶対位置を、**耳と手を直結させながら**体に染み込ませる自習用PWAアプリ。

「音が鳴ったら指が動く」感覚を養うため、理論の暗記ではなく反復タップによる身体化を重視した設計です。

---

## コンセプト

- **2タップ方式** — まず基準音（Root）をタップして耳と指板の位置を結びつけ、次に度数音をタップして答える
- **音を聴いてから探す** — 問題音を毎回再生し、音名を見る前に音で感じる
- **指板全体を活用** — 高レベルでは基準音の弦・オクターブもランダム化し、特定ポジションへの依存を排除

---

## 機能

### 正解・不正解フィードバック演出（v1.16、全モード共通）

正誤の手応えを強化するため、指板上の色フィードバックに加えて音と画面演出を追加。

- **音**: 正解＝明るい2音のチャイム、不正解＝低いブザー音。ハンバーガーメニューの波形設定（sine/triangle/sawtooth/square）とは独立した固定音色
- **画面演出**: 大きな○（正解）/✗（不正解）を画面中央にオーバーレイ表示。○は0.5秒ほどふわっと出て消え、✗は0.2〜0.3秒の短く鋭い出方＋画面シェイクで「間違えた」ことを確実に伝える。○/✗はテキスト文字ではなくSVGで自前描画しており（v1.16.1）、ブラウザ・OSのフォント差による線の太さのばらつきが出ない
- **表示タイミング**: 不正解は間違えるたびに毎回発火。正解は「1問（1コード）を全部クリアした瞬間」にのみ発火し、個々の正解タップごとには発火しない（発見モードの構成音探索・アルペジオモードの音順タップいずれも、途中経過は進捗テキストのみで伝え、大きな○は最後の1音が揃った瞬間だけ）
- オーバーレイは `pointer-events: none` のため表示中も指板タップ操作を一切ブロックしない

### インターバル編（v1.0 実装済み）

| LV | 出題音 | 基準音 | 判定弦 |
|---|---|---|---|
| LV.1 | R・3rd・5th | C 固定 | 低音3弦（6〜4弦） |
| LV.2 | +2nd・4th | C 固定 | 低音4弦（6〜3弦） |
| LV.3 | +m3・m7 | E/A/D/G/C/B ランダム | 低音5弦（6〜2弦） |
| LV.4 | +6th・#5 | 12音フルランダム、6〜4弦×0/1oct | 全弦 |
| LV.Max | 全12音 | 12音フルランダム、6〜4弦×0/1oct | 全弦 |

- **練習モード自由設定（v1.19）**: 練習モード（タイムなし、好きなだけ反復）は「練習モード（タイムなし）」ボタンから設定画面を経由して開始する。判定弦範囲（コードトーン編と同じデュアルハンドルスライダー、3〜6本）・基準音ランダム化（OFF=C固定／ON=12音フルランダム）・出題度数（12種類の度数から複数選択、最低1つ必須）を自由に設定できる。デフォルトは従来通り「R・3rd・5th、C固定、低音3弦」。LV.1〜LV.Maxの固定ルールには影響しない
- 10問セット制、タイムランキング上位20件をローカル保存
- 正解時に 0.5 秒後自動で次問、不正解は色フィードバック＋音・画面演出（v1.16）で同ポジション待機
- ホーム画面の各LV横の🏆ボタンから、プレイせずにそのLVのランキングだけを確認可能
- 詰まった時のヒント表示（5〜7秒無反応でフェードイン表示、スコア・ランキングへの影響なし、ハンバーガーメニューでON/OFF切替可、デフォルトON、LV.Maxのみ対象外）

### コードトーン編〔発見モード〕（v1.13 実装済み）

コード名を聴いて、構成音を指板上ですべてタップする形式。「コードの中に何があるか（構成音の同定）」を鍛える。

- **現在**: 練習モードのみ（タイマーなし・無限ループ）。ルート音は毎回ランダムに変わる（12音すべて・弦やオクターブも変化）。コードタイプはメジャー / マイナートライアドに加え7th系8種類（maj7, min7, dom7, dim7, m7b5, aug, sus2, sus4）も含めた全10種類に対応済み
- **テンション対応**: 各コードタイプに定義済みのテンション（9th・b9・#9・11th・#11th・13th・b13）から毎回1個だけランダムに選び、基本構成音とあわせて出題する（ジャズの「アベイラブルテンション」の考え方に基づき、全部同時ではなく1個を選ぶ設計）。オクターブは無視し、ピッチクラス一致のみで正解とする（鳴っているコードの中でどの音を弾くかという演奏上の判断を問う設計のため、基準音との物理的な距離を問うインターバル編とは判定基準が異なる）。実質音数はコードタイプごとに3〜5音（sus2=3音固定、7th系=5音）。sus2はテンション抽選の対象外（唯一の定義済みテンション9thが基本構成音2ndとピッチクラス衝突するため）で常にテンションなし
- **コード名表示**: 「コード記号＋括弧でテンション」形式で表示し、選んだテンションを含む音数と一致させる（例:「C7(9)」「Cmaj7(#11)」「Csus4(9)」。sus2やテンションが選ばれない場合は括弧なし）。ジャズの慣習的な省略記法（「C9」が7thを暗黙に含む等）は採用しない
- 出題は「ルート×コードタイプ×テンションの組み合わせ単位」で可解性チェック（表示窓・判定弦内に構成音セット全体が収まるか）を通過したものだけが選ばれる。ルートが可変になっても、ルートPC・ルートポジション・コードタイプ・テンションをまとめて再抽選する動的リトライで「詰み」を回避する。6フレット窓という表示範囲は「実際の運指で無理なく弾ける1ポジション分」というアプリのコアコンセプトのため固定
- 判定は「未クリア集合」方式: 構成音（テンション込み、例: R・3rd・5th・7th・9th）をタップ順不同で探し、見つけた度数を集合から消す。常時「R ✓　3rd ✓　5th（未）」のようなテキストで進捗表示
- コードは複数音を同時発音（ストローク再生）。テンションは基準音から実際の物理的な高さ（オクターブ込み）で鳴る
- 「練習をはじめる」の直前に判定弦選択画面が表示され、デュアルハンドルスライダーで判定対象弦を3〜6本の範囲で自由に選べる（ルート音の出現弦も連動、アルペジオモードと共通の設定。デフォルトは低音3弦＝6〜4弦）
- **出題コード範囲設定（v1.15、v1.18でUI再設計）**: 同じ判定弦選択画面に「出題コード範囲」（トライアドのみ／7th系まで）と「テンション」（OFF／ON）という独立した2つのスイッチがある。内部的には`{ chordTypeRangeAll: boolean, tensionEnabled: boolean }`という2軸で状態を持ち、UIもその2軸をそのまま2つのスイッチとして見せる（v1.15.0時点では「トライアドのみ／7th系まで／全部」という3プリセットボタン＋独立テンショントグルという構成だったが、「7th系まで」と「全部」がコードタイプとしては同一でテンション有無だけの違いという分かりにくい重複があり、手動でテンションだけONにするとプリセットがどれも非選択の「どこにも選択の印がない」状態になっていたため、v1.18.0で2つの独立したスイッチに再設計した）。この設定はアルペジオモードとも共有される
- 出題順序制約（順序固定⇄順不同を段階的に混ぜる案）は今後のステージで検討予定

### コードトーン編〔アルペジオモード〕（v1.14 実装済み）

コードをストローク→アルペジオの順で聴いて、聞こえた音の順番どおりに指板上をタップして再現する形式。「聞いた音の順序の記憶と再現」を鍛える、発見モードとは役割の異なる新モード。

- **現在**: 練習モードのみ（タイマーなし）。ルート音は毎回ランダムに変わる（12音すべて・弦やオクターブも変化）。コードタイプは発見モードと同じ全10種類（maj, min, maj7, min7, dom7, dim7, m7b5, aug, sus2, sus4）に対応（テンションは対象外）
- コード名は発見モードと同じ記号表記で表示（例:「C7」「C#dim7」。テンション非対応のため括弧は付かない）
- 出題の流れ: ①コードをストローク再生 → ②構成音をランダムな順序でアルペジオ再生 → ③再生完了後、聞こえた順番どおりにタップ。再生中（合計2〜3秒程度）はタップを無視する
- 判定は「フェーズ管理」方式（インターバル編と同型）: 今何番目の音を待っているかのポインタを持ち、正しいピッチクラスがタップされたら次へ進める。構成音でも順番違いのタップは通常の不正解と同じ扱い
- 進捗表示は度数名を隠し、「1音目 ✓　2音目 ✓　3音目（待機中）」のように順番のみ表示（7th系は4音構成のため「4音目」まで表示）
- 「もう一度」でストローク＋アルペジオを最初から再生し直せる（進捗は保持されたまま）。詰まった時のヒント表示にも対応（次に鳴らすべき音の位置を表示）
- 発見モードの可解性チェック（`hasSolvableChordTones()`）をそのまま流用
- 「練習をはじめる」の直前に判定弦選択画面が表示され、デュアルハンドルスライダーで判定対象弦を3〜6本の範囲で自由に選べる（ルート音の出現弦も連動、発見モードと共通の設定。デフォルトは低音3弦＝6〜4弦）
- **出題コード範囲設定（v1.15、v1.18でUI再設計）**: 発見モードと共通の「出題コード範囲」スイッチ（トライアドのみ／7th系まで）が適用される。アルペジオモードはテンション非対応のため、発見モードにある「テンション」スイッチは表示されない
- テンション対応・出題度数の部分集合選択・不正解時を「一発勝負＋制限時間」に変える案は今後のステージで検討予定

## 指板表示の仕様

- **表示範囲**: 基準音を中心とした6フレット幅（0F〜17F 内で動的に決定）
- **開放弦**: ナット左側に専用ゾーンを表示、タップ可能
- **ポジションマーク**: 3・5・7・9・12・15・17F（実際のギターに準拠）
- **フレット番号表示**: 指板の下側（弦のすぐ下）に表示（v1.17.0）。タップする弦やコード名・進捗テキストなど他の確認情報が指板より下に集まっているため、視線の動線に合わせた配置
- **出題バリデーション**: 「18F以上にしか正解がない」問題は最大30回のリトライで自動排除

## PWA 対応

- ホーム画面に追加してオフライン動作
- `manifest.json` で横持ち（landscape）固定
- 縦持ちアクセス時は「横向きにしてください」オーバーレイを表示
- ハンバーガーメニュー最下部に現在のバージョン番号を表示（例: `v1.16.0`）

## ローカルでの起動方法

iOS Safari で Web Audio API を使うには **HTTPS** が必要です。

### 1. 証明書の生成（初回のみ）

```bash
brew install mkcert nss
mkcert -install
mkcert 192.168.x.x localhost 127.0.0.1
# 生成された .pem ファイルを cert.pem / key.pem にリネーム
```

### 2. サーバー起動

```bash
node server.js
```

iPad/iPhone から `https://192.168.x.x:3443` でアクセス（同一 Wi-Fi 必須）。

## v1.7 以降に保留している機能

- **コードトーン編 Stage 7以降** — 出題度数の部分集合（発見モード・アルペジオモード個別に検討）、出題順序制約、アルペジオモードの不正解時を「一発勝負＋制限時間」に変更する案、アルペジオモードのテンション対応（なお、v1.15で追加し v1.18 でUI再設計した出題コード範囲・テンションの2軸は、将来LV概念を設計する際の骨格としてほぼそのまま使える可能性が高い）
- **指板幅の可変設定** — 表示フレット幅を 5・6・7 から選択
- **ハプティクスフィードバック** — 正解・不正解を振動で区別（iOS PWA 限定）
- **CAGED システム表示** — 正解後に該当ポジションのケイジドフォームをハイライト
- **カスタム出題設定** — 出題度数をユーザーが個別に指定
- **音源の追加** — サンプラー音源（実際のギター音）への対応
